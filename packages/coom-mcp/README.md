# coom-mcp

An MCP server that gives AI assistants access to models of the [COOM](https://www.coom-lang.org) product
configuration language, for checking, navigating and solving them. The server is under development and this release
contains no tools yet. Sources live in the [coom-lang repository](https://github.com/denkbares/coom-lang) under
`packages/coom-mcp`.
